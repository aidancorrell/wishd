ADR-002's rule is no build step and no external assets: a CDN icon font would break an air-gapped install and phone home from a deployment that must not, so these are hand-drawn glyphs with `currentColor` fills that inherit whatever the surrounding text is. They are marks, not logos. Reproducing vendor trademarks in an Apache-2.0 repo is a licensing question nobody wants; a recognisable *shape* per platform (a DAG for Airflow, a chevron stack for Spark, a snowflake for Snowflake) carries the same meaning at 14px without borrowing anyone's brand.
